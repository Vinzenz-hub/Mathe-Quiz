# Mathe-Quiz – Zahlenraum bis 1000

Ein interaktives, deutschsprachiges Mathe-Quiz zum Üben des Stellenwertsystems.

## Funktionen

- Zahlen mit Hundertern, Zehnern und Einern darstellen
- Umgekehrte Aufgaben: dargestelltes Material ablesen und die Zahl eingeben
- Bausteine per Drag-and-drop oder Antippen hinzufügen
- Alternative Plus-/Minus-Schaltflächen
- Automatische Rückmeldung, Punktestand und Abschlussauswertung
- Responsives Layout für Computer, Tablets und Smartphones

## Starten

Die Datei `index.html` herunterladen und im Browser öffnen. Es sind keine zusätzlichen Installationen oder Server erforderlich.

## Online veröffentlichen

GitHub Pages lässt sich im Repository unter **Settings → Pages** aktivieren. Als Quelle **Deploy from a branch**, Branch **main** und Ordner **/(root)** auswählen. Danach wird die Website über die von GitHub Pages angezeigte Adresse erreichbar.
